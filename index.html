¡Bienvenidos!

Esta es mi primera página web creada utilizando HTML y CSS. En ella pongo en práctica mis primeros conocimientos de desarrollo web y programación.

Sobre este proyecto

El objetivo de este proyecto es aprender a crear una página web, organizar su contenido y darle un diseño utilizando CSS. También aprenderé a publicarla en Internet mediante GitHub Pages.

Lo que estoy aprendiendo

CSS

Permite agregar colores, diseños y estilos.

GitHub

Permite guardar proyectos y publicarlos en Internet.
